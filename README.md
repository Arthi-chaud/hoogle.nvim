# 🫂 Snoogle

_[Snacks.nvim](https://github.com/folke/snacks.nvim)_ + _[Hoogle](https://github.com/ndmitchell/hoogle)_ = _Snoogle_

**Snoogle** is a Neovim plugin that lets you look through a local Hoogle database.
